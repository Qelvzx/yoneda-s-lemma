# The ∞-Categorical Yoneda Lemma

A research-style expository note on the Yoneda lemma in the setting of quasicategorical ∞-category theory.

The manuscript presents the Yoneda equivalence through:
- representable left fibrations,
- straightening–unstraightening,
- sections as limits,
- and finality in slice ∞-categories.

The proof is organized structurally rather than objectwise, treating representability geometrically through slice left fibrations.
